# FLOODINTEL viewer

Research prototype of FLOODINTEL, a flood digital twin built on satellite data
(NESFIC 2026, problem NESFIC-D-18).

The viewer shows measured outputs for a test basin (Lower Periyar, Kerala):
Sentinel-1 flood maps checked against official NDEM maps, a validated flood-susceptibility
map, height above nearest drainage, yearly impervious area (2017-2025), UICA and its change,
and click-to-inspect of every layer at 30 m.

Open `index.html`, or the GitHub Pages link of this repository.
